Collega GitHub

Serve solo la prima volta su questo dispositivo. Il codice resta salvato qui e permette alla pagina di pubblicare le foto sul sito.

  1. Apri questa pagina di GitHub (accedi se te lo chiede).
  2. Token name: scrivi Galleria sito. Expiration: scegli 1 anno (o “No expiration”).
  3. Repository access → Only select repositories → scegli dodoleiro-s-website.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Premi Generate token, copia il codice (inizia con github_pat_) e incollalo qui sotto.
